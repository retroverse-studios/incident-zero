# Playtesting Incident Zero (v2.2 Playtest Edition)

Everything you need to run a playtest session and send useful feedback back to the project.

---

## What v2.2 Is

v2.2 is a **consistency + balance pass** over v2.1: every module's rules, standalone guide, and card deck now agree with each other, and several known dominant strategies were patched. Each module rules doc ends with a **"v2.2 Playtest Edition Changes"** section listing exactly what changed and why — those changes are the hypotheses your playtest validates.

## Session Checklist

**Before (15 min):**
1. Pick ONE module for your first session — recommended: **Incident Response** (most developed) or **Audit & Compliance** (simplest to run)
2. Read: [How to Play](../HOW_TO_PLAY.md) + the [TO Guide](../TO_GUIDE.md) (facilitator) + your module's rules doc
3. Print: [tracker sheets](../../cards/print-templates/tracker-sheets.md) (universal + your module's sheet) and cards per the [A4 guide](../../cards/print-templates/a4-layout-guide.md) — index cards are fine for a first run
4. Print one [session notes form](session-notes-form.md) (facilitator) and one [feedback form](feedback-form.md) (group)
5. Bring: one d20, one d4, one d6, pencils

**During:**
- Facilitator logs each turn on the session notes form (action, cost, roll, result, budget)
- Note every rule lookup or argument in the friction log — those are the most valuable data points
- Don't house-rule silently; if you must, write it down

**After (10 min):**
- Run the module's debrief questions (they're part of the game)
- Fill in the feedback form together
- File the results: open a GitHub issue titled `Playtest: <module> <date>` with both forms' contents, or email them to the maintainer

## What We Most Need Data On

1. **Session length** vs. the claimed 30-45 min per module
2. **Turn formula** — does (Attack Cards × 2) + 1 pace well?
3. **The v2.2 balance patches** (checklist on the feedback form): IR reveal/dwell economy, Hardening playbook cap, Forensics Analyze cost, DR ransom dilemma, NB free placement
4. **Rules clarity** — anything you had to re-read twice
5. **Learning** — could players explain one new concept afterward?

## Player Counts

- Minimum: 2 (one Threat Orchestrator + one defender) — most modules
- Sweet spot: 1 TO + 3-4 Blue Team
- Audit & Compliance Variation C (debate format) works with larger groups (6-10)
